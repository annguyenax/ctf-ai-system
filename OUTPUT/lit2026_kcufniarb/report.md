# kcufniarb (LIT 2026)

## Summary
The challenge provided a Brainfuck-like script where all operations and the script direction were reversed (hence the name kcufniarb). By swapping the characters <>+-[]., to their opposites and executing the resulting valid Brainfuck code, the script prints out the flag.
