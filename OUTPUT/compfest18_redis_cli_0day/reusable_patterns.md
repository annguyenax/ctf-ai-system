# Reusable pattern: client-side cluster metadata parser

When a network client parses a server-provided fixed-domain identifier into an array, do not assume protocol compliance. Trace both singleton and range grammar paths. For Redis cluster slots, valid IDs are `0..16383`; test `16384` first because it demonstrates a one-byte adjacent write with minimal malformed input. Correlate source to shipped code using DWARF line information and the specific indexed-store instruction before claiming a defect. Separate proof of the OOB primitive from proof of a reliable allocator-dependent exploit.
