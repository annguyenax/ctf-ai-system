# Reusable pattern
When a "revenge"/multi-layer challenge has a cover page + instruction page + data pages,
OCR the cover FIRST: its instruction sentences' first letters may spell the flag (acrostic).
Also common in this family: numbers -> mod N ("wheel with N teeth") -> custom base64-ish
catalog -> keyed transposition -> base64 decode. The flag is often the transposition key
(a short word) rather than the decoded payload.
