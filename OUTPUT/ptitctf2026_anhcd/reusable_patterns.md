# Reusable patterns

- Separate intentional embedding from flag verification. A cleanly decoded flag-shaped string can still be a decoy.
- A length field before RGB-LSB payload bytes proves deliberate insertion, not truth of the payload.
- Text painted into FFT magnitude appears twice because real spatial images have conjugate-symmetric frequency content.
- Calibrate statistical stego detectors against clean recompressions before trusting a positive score.
- When broad transforms fail, require a new artifact signal or hint before expanding the search space.
