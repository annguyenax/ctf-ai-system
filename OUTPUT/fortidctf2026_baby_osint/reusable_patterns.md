# Reusable patterns

- For event photos, inspect EXIF timestamps early; they can reduce a broad scene search to one date.
- Search the exact local-language event title and preserve its official spelling before normalizing the flag component.
- For data questions, inspect the page's embedded JSON and linked public APIs instead of estimating from a chart.
- Pin the observation date and query range when the source is a live dashboard; its values can change after the solve.
- Translate ordinary answer words such as weekdays when the challenge explicitly requires English.
