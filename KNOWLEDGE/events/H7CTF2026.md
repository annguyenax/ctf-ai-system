# H7CTF 2026 Quals — Event Digest (Batch 2)

Full batch-2 worklist for this event (48 challenges). Recurring techniques observed across this batch:

- Mobile/API challenges repeatedly hinge on decompiling the Android APK first to recover a hardcoded header/pepper/handshake, then replaying the raw API directly rather than fuzzing blind or trusting client-side UI gating.
- Reverse-engineering license-style binaries (5 of 5 Reverse challenges) follow the same shape: independently invertible per-byte/per-chunk constraints in .rodata tables, solved analytically or by brute force, feeding a hash(key)->AES-CBC(IV=0) decrypt rather than the key itself being the flag.
- Several Hardware/RF challenges hide the decode recipe in a readable side-channel (UART boot log, BLE debug characteristic) before any waveform math is needed.
- Forensics challenges repeatedly reward checking cheap/raw evidence first (plain strings over a memory image, raw bytes of a SQLite file, ctime/crtime vs. forgeable atime/mtime) before any "intended hard path".
- Crypto challenges consistently exploit a deterministic/reused secret (stuck AEAD nonce, LCG/polynomial ECDSA nonce, shared RSA primes, tiny key space) rather than any weakness in the cipher primitive itself.
